Attaching a document to a style

Some packaging lines on a cover page are supplied by hand rather than produced here. This is where the actual file goes — one drop zone per line, labelled exactly as the cover labels it.

Open a style, then the Prod Spec tab — the section called Manually supplied packaging, just above Prod Spec runs.

1 What a manually supplied line is

The cover page lists everything the order’s trims column asks for. Some of those lines this app produces itself — the care label, the carton marking, whatever layouts the client has. The rest it doesn’t, and the cover says so: manually supplied, with the status column reading “Waiting for Customer Information”.

The cover has already told the supplier to expect that document. This screen is where you put it. Dropping a file here places it in the same APPROVED LAYOUTS folder the generated outputs land in, and flips that line on the cover from waiting to approved.

Only lines the cover is actually printing get a zone

The labels come from the very same list the cover renders, so nothing here is re-typed or paraphrased. If the cover says “Wash Care Label with Oeko-tex Logo”, so does the zone — that identity is how you tell which file belongs in which box.

It follows that a line the cover isn’t printing has no zone. If a style has nothing manually supplied, the section says so: every packaging line is produced here. And if trims on the cover page are switched off entirely, no cover lists a manual line at all, and the section tells you that instead.

3 When the cover catches up

A cover already generated keeps its words until it is rebuilt

A bundle generated after the upload carries the new status straight away. One that already exists — including one already sitting in the supplier’s folder — still says “Waiting for Customer Information” until it is rebuilt.

The Regenerate cover pages sweep on Settings ▸ Cover page now sees this style as changed and will rewrite it. For a single order in a hurry, Regenerate a style on the same screen does it immediately — guide 4.

4 When a trims list changes underneath you

If the order’s trims column changes after you have uploaded something, a file can be left behind: still in the supplier’s folder, no longer on the cover. Those are collected in their own amber box.

5 Who can do this

Anyone who can review

Reviewers and admins alike. It sits on a tab reviewers already reach, and the routes behind it use the same permission — because chasing a missing hangtag artwork is reviewer work, not configuration.

A useful check: a document line stuck at “Waiting for Customer Information” on a cover you are reviewing usually means exactly this — nobody has attached the file yet. Open the style’s Prod Spec tab, find the zone with the same heading, and drop it in.
