Carton barcode format — EAN-128 vs EAN-13

How to choose the barcode symbology for a carton-marking output — EAN-128 (Code 128) or EAN-13 — and set its bar height. A per-output setting in the Prod Spec editor.

Admins only · set under Prod specs ▸ open a spec ▸ a Carton marking output. It changes only the carton (outer-box) barcode — never the per-size product EANs.

1 What it controls

Carton-marking labels carry the carton EAN (the outer box's number). This setting decides how that number prints — as EAN-128 / Code 128 bars with the digits beneath (the default), or as a true EAN-13 retail symbol. It's set per output, so two carton outputs on the same spec can differ.

It only touches the carton barcode

The per-size product EAN-13s on care labels, price stickers and the like are always true EAN-13 and are not affected. This switch is exclusively the carton/outer-box barcode ({{barcode:cartonEan}} in builder layouts, and the carton-marking templates).

2 Where to find it

Open the spec, find the carton-marking output, expand its 📌 … · preview panel — the Carton barcode dropdown sits at the top, next to Bar height mm.

The dropdown only appears on carton-marking outputs

It's shown solely for outputs whose document type is CARTON_MARKING. On a care label, price sticker or any other output the control is hidden — there's no carton barcode to switch there.

3 The two formats

Pick the one the customer's carton spec asks for. When unsure, leave it on the default — EAN-128 is the historic carton marking.

Default EAN-128 (Code 128)

  • Carton EAN encoded as Code 128 bars, with the number printed beneath the bars.
  • The historic carton-marking look — use it for most master-carton labels.
  • Handles the full carton number cleanly; not a retail till symbol.
  • Stored as nothing — it's what you get when the setting is left alone.

Alt EAN-13

  • Carton EAN printed as a true EAN-13 retail symbol, digits inside the guard bars.
  • Use when the carton must carry the same scannable EAN-13 as the product.
  • Requires a valid 13-digit EAN — a non-EAN number won't encode.
  • Chosen explicitly from the dropdown; stored on the output.
Good to know

“EAN-128” here is plain Code 128 of the carton number — not GS1-128 with application identifiers (the (00)/SSCC style). If a customer ever needs true GS1-128, that's a dev change, not this dropdown.

4 Where the setting takes effect

Save and it applies everywhere that carton output is rendered — the in-editor preview, the downloadable PDF, and every future generation of that output. Both rendering paths honour it.

1Set it on the output in the Prod Spec editor (per carton-marking output).
2It's applied at render time to the carton barcode — the coded carton-marking templates and Output Builder carton layouts both read it.
3Preview and final PDF match — the live preview and the generated document use the same setting, so what you approve is what prints.
