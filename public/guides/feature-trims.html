The trims list

Every order carries a Trims list on Monday — the buyer’s own words for what the order needs. This screen is where those words are given a meaning, so the cover page can print the list and say which lines we produce.

Settings ▸ Trims. Nothing here renders a PDF, sends anything, or arms a queue — it only decides what words mean.

1 Why words need a meaning at all

The cover page prints the buyer’s trims list in Monday’s own words, so the supplier can tick it off, and marks each line as something we produce, something supplied separately, or a packing instruction with no artwork. To do that it has to recognise what each line is.

A trim is never matched to one layout. “Care label” exists once per client, so that mapping would never be finished — it would have to be redone for every new customer. Both sides are matched onto a shared concept instead:

Monday saysWash Care Label with Oeko-tex Logo
A layout is calledAcme Apparel - Kids - Care Label
→
the concept Care label
A style satisfies a trim when any document it already declares carries the same concept. So “Hangtag” is produced by us for a client who has a hangtag layout, and supplied separately for one who doesn’t — with no per-client setup.
Some concepts have no artwork — on purpose

A large share of live trims are physical packing instructions with nothing to print: master polybags, hangers, cartons, hooks. Those are listed on the cover so it matches the buyer’s list one for one, but as a note — never as a document with a delivery status, which would otherwise sit at “waiting” forever and bury the lines genuinely waiting.

  1. 1Trim values — the vocabulary Monday actually uses, and the queue of words waiting for a person. The count in the tab is how many still need one.
  2. 2Rules — the ordered keyword rules that classify both sides. Order is meaning here: the first rule that matches wins, so sorting the list alphabetically would silently re-label thousands of styles. The screen says so in an amber banner, and the arrows move a rule up or down.
  3. 3Layouts — a layout is classified from the last part of its name (“Acme Apparel - Kids - Care Label”). You only set one by hand when that name can’t be read, or when the document answers no trim at all.
  4. 4Only show what needs a decision is on by default, on both the Trim values and Layouts tabs. It hides everything already resolving cleanly. Untick it to see the whole vocabulary.
  5. 5Everything saves in one press. Edits are collected locally and sent together, because a half-applied rule set classifies like neither the old one nor the new one. The page reloads afterwards so every count on screen is recomputed rather than half-patched.

Coverage is the fourth tab — see section 5.

3 Only the words that still matter

The list used to cover every style ever scraped, which meant vocabulary from long-dead orders sat in the queue and shaped the rules for orders nobody will ever print. It is now scoped to the generation PO cutoff — only orders that will actually be printed.

164 distinct values across the whole book → 88 once scoped to the generation cutoff (PO 100000 and above). 76 values live only on orders we will never print, and are no longer asked about.
812 styles in scope · 4,930 parked below the cutoff · 260 with no PO number at all. 3 carry a PO number that doesn’t parse onto the timeline — those are kept, because generation keeps them too.
  • 1Below the cutoff — the order predates what we print. Its words are parked, not deleted.
  • 2No PO number at all — a placeholder that will never be delivered. Its words are not put in front of anyone.
  • 3A PO number that doesn’t parse — kept, because generation keeps those styles too. The numbers are shown separately so the split is visible rather than assumed.

This is the generation cutoff specifically — not the scrape cutoff (how far back we re-pull data) and not the supplier-send cutoff (what leaves the building).

4 A suggestion versus a decision

Most values need nothing from you. The keyword rules already resolve them, and they keep following the rules — so if a rule is later improved, they improve with it. Setting a value yourself is a different thing: it becomes a stored decision that no later rule change can move.

  1. 1“rule” — a keyword rule matched, and this value is following it. Nothing needs doing. Leave it on Auto and it keeps following the rules as they improve. The badge reads “override” instead once somebody has decided it by hand.
  2. 2“check” — several rules matched and the first one won. It is probably right, but a person should confirm it. These count toward the tab’s “to check” number.
  3. 3“unmapped” — genuinely new vocabulary. Nothing recognises it, so the cover prints the line as supplied separately until somebody maps it. That is the safe direction: a supplier never loses a line while it waits.
  4. 4“Not packaging — hide it” keeps a value off the cover entirely. Use it for one-offs that were typed into the column but aren’t trims — a PO number, a note to the buyer.
Choosing a concept

The dropdown lists the whole catalogue: care label, carton marking, colour sticker, hangtag, banderole, neck print, main label, size label, price sticker, barcode sticker, polybag sticker, info area, top card, pictogram, heat transfer, RFID — and the ones with (no artwork) beside them: polybag, hanger, carton/box/display, hook, packing instruction. Picking a “no artwork” concept means the line prints as a note, with no delivery status.

Start the vocabulary over — admins only

Decisions made before the list was scoped may have settled words no live order uses any more. Review stored decisions… shows exactly what is stored, how many in-scope styles still use each, and how many are parked — then lets you drop the lot. That re-opens every value for mapping; the keyword rules and the layout pins are left alone. It cannot be undone from here: each decision has to be made again.

In practice: open the Trim values tab, leave the filter on, and work down the short list. Confirm the “check” rows, map the “unmapped” ones, hide anything that isn’t a trim at all — then Save. If the same word keeps reappearing in slightly different spellings, the better fix is a keyword on the Rules tab, not a decision per spelling.
