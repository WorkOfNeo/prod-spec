Writing what the cover page says

Every packaging line a cover page can print is written once, here — its name, the standing note under it, and the two wordings its status column uses.

Settings ▸ Cover page ▸ Packaging rows, the third tab beside Cover page (all clients) and General information.

1 One list, not one per client

A row is written once and shared by every client. That is the whole point: “Care label” is a different layout for each client, so a per-client list would have to be re-done for every customer we take on and would never be finished.

The rows are the shared targets. Which Monday trim values land on which row is a separate decision, made on Settings ▸ Trims — see guide 2. This screen decides what a row is called and what it says; that one decides what reaches it.

1The buyer writes a trims list on Monday, in their own words.
2Settings ▸ Trims decides which packaging row each of those words means.
3This screen decides the wording that row prints — its name, its note, and its two status wordings.
4The cover page prints the order’s list, one line per row, with a status beside each.

  1. 1The row’s name. This is the heading the cover prints for the line, so write it the way a supplier should read it.
  2. 2“Packing instruction — no file, so no delivery status”. Tick this for anything physical with nothing to print: polybags, hangers, cartons, hooks. The line still appears on the cover, so the buyer’s list is matched one for one — but as an instruction, with no status column. Leave it unticked and the row is a document, and gets a status.
  3. 3“built in” marks a row that ships with the app rather than one somebody added here. Both kinds are edited the same way.
  4. 4The note is a standing fact about the document. It prints in every state — whether the artwork has arrived or not — so put permanent instructions here, never anything time-dependent.
  5. 5Not yet delivered is what the status column says while the artwork is still to come.
  6. 6Delivered is what it says once the document is confirmed in the supplier’s folder.
An empty box is not a blank line

Leave either status box empty and the row prints the wording shown greyed inside it — the default. Type in the box only when this particular row should say something different.

3 The two shapes a row can take

A document row has a status
Care labelWaiting for Customer Information
Something with a file behind it. The cover prints the line, the note, and a status that moves from the “not yet delivered” wording to the “delivered” one once the document is in the supplier’s folder — whether we produced it or somebody attached it by hand (guide 5).
A packing instruction no status
Master polybag
Something physical with nothing to print. The line and its note appear so the supplier sees the whole list, but there is no status column — because a status that can never be satisfied would sit at “waiting” forever and bury the lines genuinely waiting.

4 When a change reaches a supplier

Changes apply to newly generated bundles

Editing a row changes what is generated from now on. A cover PDF already sitting in a supplier’s folder keeps the words it was built with until it is rebuilt.

To push a wording change out to bundles that already exist, use the tools on the General information tab next door — Regenerate a style for one order, or Apply to existing bundles for a whole client. Guide 4 covers both.

5 Adding and removing rows

Add a row when the buyer keeps asking for something the list has no line for. Then go to Settings ▸ Trims and point the Monday wording at it — a new row on its own changes nothing until something resolves to it.

Before you remove one

Remove takes the row out of the shared list for every client. Check Settings ▸ Trims first for values pointing at it: a trim value whose row has gone has nothing to resolve to, and will print as supplied separately until it is mapped somewhere else.

Rule of thumb: the row name is what it is, the note is what is always true about it, and the two status boxes are where it has got to. If you find yourself wanting to write “still waiting” in the note, that belongs in the Not yet delivered box instead.
