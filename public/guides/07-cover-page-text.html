The cover page & General information

The two blocks of text that ride in front of every bundle — and how to write them yourself, without asking an admin.

Open it from Cover page in the sidebar (under Delivery).
This is new — it used to be admin-only

Standing instructions to suppliers (“the pictogram is handed over by the supplier”, inspection standards, contact lines) are your knowledge, not configuration. So you can now write them directly. Nothing on this page can change what a style generates, which languages it prints, or whether it's approved — it only changes words on paper.

Which one do I want? If it's true for every supplier we work with → cover page. If it only applies to one client (or one of that client's business areas) → General information.

Switching clients is safe

Pick another pair and the editor reloads that client's text. Your previous edit is already saved — the status stamp told you so before you switched. There is no “unsaved changes” trap here.

5 Making the change reach bundles that already exist

Your edit applies to everything generated from now on, automatically. Bundles already generated keep the old wording until you refresh them — that's what the panel at the bottom of each tab does.

  1. 1On the General information tab this is scoped to the client you're editing — usually a handful of styles. On the Cover page tab it's called Regenerate cover pages and covers the whole estate, which is thousands. Same button, very different size.
  2. 2Nothing happens until you read this count and press Start. Cancel is free.
  3. 3Leave this ticked. A fully-approved style's cover shows no status column, so rebuilding it changes nothing anyone can see — while still overwriting the file for a finished order. Untick only if you changed something that shows on every cover.
  4. 4This is the one that leaves the building. Ticked, suppliers get the new cover in their SharePoint folder and a line in tonight's digest email. Untick it if you're fixing a typo and don't want to ping anyone — the covers still update in-app.
  5. 5Live progress. You can press Stop mid-run; it's safe to start again later, and already-done styles aren't redone twice.
Outputs and approvals are never touched. This rebuilds the cover PDF only — no care label is re-rendered, nothing goes back for re-review, and no approval is undone.

6 Worked example — adding a standing note

“Every supplier must be told the pictogram is handed over by them.” Start to finish:

1It's true for every client, so it's the shared block. Sidebar → Cover page → stay on Cover page (all clients).
2Click at the end of the text and type the sentence. Wait for “Saved · …”.
3Check the Cover preview on the right — your line should appear under the packaging list.
4Every bundle generated from here on carries it. You can stop here if that's enough.
5To reach orders already out: Regenerate cover pages → read the count → keep “Skip … all approved” ticked → decide on the supplier push → Start.
If you're not sure about step 5

Ask before running the whole-estate sweep. It re-pushes files to suppliers for live orders, and there's no undo. The scoped one on the General information tab is much smaller and safer.
